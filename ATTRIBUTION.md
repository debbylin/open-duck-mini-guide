# Sources, notices and modifications

## Open Duck Mini

Original project: Antoine Pirrone and contributors, [Open_Duck_Mini](https://github.com/apirrone/Open_Duck_Mini).

Assembly photographs, CAD screenshots and wiring illustration embedded in `index.html` originate from the upstream v2 assembly guide and motor configuration guide at commit `b23317a485b3cec7d8417f352478778b3475173c`. These are original reference images, separate from the newly drawn schematic.

The upstream Apache License 2.0 is reproduced in `LICENSE-UPSTREAM.txt`. Original source documents remain available through the links in the guide. Modifications in this project consist of a Chinese instructional summary, an interactive simplified SVG schematic, a 15-servo purchase allocation (14 installed, one spare), a parts checklist and an offline presentation of the original reference images. No original photograph has been presented as a newly created CAD model.

Runtime references: [Open_Duck_Mini_Runtime, v2](https://github.com/apirrone/Open_Duck_Mini_Runtime/tree/v2), especially the README and example configuration.

Camera connector reference: [Raspberry Pi camera installation documentation](https://www.raspberrypi.com/documentation/accessories/camera-software.html).

## Anatomy

The generated SVG figure, CSS, page frame and inline geometry helpers use the [Anatomy](https://github.com/wheresryan22/anatomy) toolkit, distributed under the MIT license. A copy of its license is included in `LICENSE-ANATOMY.txt`.

This is an unofficial assembly aid. Simplified part envelopes are intended for identifying subassemblies; exact holes, servo axes, fasteners, insertion paths and cable routes must be checked against the original CAD and actual components.
